# Aakash Shetty — Portfolio

Personal portfolio website built with React and Vite, showcasing projects, experience, and skills.

## Sections

- **Hero** — Introduction and quick links (LinkedIn, GitHub, Medium, Resume)
- **Projects** — Featured work including RL Agent for Pacman and a published cloud offloading paper
- **Experience** — Professional timeline (SowFin, Harman Connected Services, Drona Automations)
- **Skills** — Languages, frameworks, DevOps tools, and core CS concepts
- **Contact** — Get in touch

## Features

- Light/dark theme toggle with local storage persistence
- Responsive layout with mobile navigation
- Single-page design with smooth section navigation

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+)

### Install & Run

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (typically `http://localhost:5173`).

### Build for Production

```bash
npm run build
npm run preview
```

The production output is generated in the `dist/` folder.

## Tech Stack

- **React 19** — UI framework
- **Vite 5** — Build tool and dev server
